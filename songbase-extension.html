To use this on a non-mobile device, drag this bookmark into your bookmark bar: Songbase chords
Then go to a song on songbase (won't work if you use this on the home page) and click on the bookmark. The extension should pop up on the website.

To use this on a mobile device, click to copy the code
Then go to a song on songbase (won't work if you use this on the home page) and type (without the apostrophes) 'javascript: ' and paste the code you copied into the search bar. The extension should pop up on the website
